
# MurrlyBot Mini App v1

Это первая рабочая версия Telegram Mini App для существующего MurrlyBot.

## Что уже есть

Пользователь:
- Главная страница с балансом мёдика.
- Медовая ферма: состояние, сбор и улучшение.
- Магазин подарков: цены, инвентарь, покупка.
- VIP: статус, бонусы, покупка двух планов.
- Профиль.
- Правила.
- Брак отображается на главной.
- Всё читает и изменяет ту же `/app/data/murrlybot.sqlite3`.

Администратор:
- Кнопка админки НЕ отправляется обычным пользователям.
- Админ-доступ разрешается только Telegram ID из `ADMIN_USER_IDS`.
- После проверки Telegram ID дополнительно требуется `ADMIN_PASSWORD`
  или `ADMIN_PASSWORD_HASH`.
- Админ-сессия создаётся на 24 часа, токен хранится в браузере только в
  `sessionStorage`, а в SQLite сохраняется только SHA-256 этого токена.
- Настройки фермы, раздач, подарков, VIP, правил и бэкапов.
- Статистика и журнал.
- Ручной запуск раздачи.
- Скачивание консистентного SQLite-бэкапа.

## Файлы обновления

- `start.py` — запускает одновременно aiogram-бота и FastAPI.
- `miniapp_server.py` — API + проверка Telegram initData.
- `miniapp_static/` — интерфейс Mini App.
- `requirements.txt` — aiogram + FastAPI + Uvicorn.

Старые файлы MurrlyBot не удаляются.

## Установка на Bothost

1. Добавь файлы этого архива в корень текущего репозитория.
2. Замени `requirements.txt`.
3. В Bothost поменяй главный файл / entrypoint с `main.py` на `start.py`.
4. Включи домен для бота.
5. Внутренний порт укажи, например, `8000`.
   Bothost передаёт выбранный порт в переменной `PORT`, код читает её автоматически.
6. Переменные оставь:
   - `BOT_TOKEN`
   - `DATA_DIR=/app/data`
   - `ADMIN_USER_IDS=<твой Telegram ID>`
   - `ADMIN_PASSWORD=<пароль>` либо `ADMIN_PASSWORD_HASH=<sha256>`
7. Сделай новый деплой.
8. Проверь в браузере:
   `https://ТВОЙ-ДОМЕН/health`
   Должно вернуть JSON с `"ok": true`.
9. В @BotFather:
   `/mybots` → MurrlyBot → Bot Settings → Menu Button
   и укажи HTTPS URL домена Mini App.
10. Открой бота и нажми кнопку Mini App в меню.

## Безопасность админки

Обычный пользователь:
- не получает `admin_eligible=true`;
- не видит кнопку «Панель управления»;
- получает HTTP 403/404 на защищённых endpoint;
- не может войти только по знанию пароля.

Для входа в веб-админку одновременно нужны:
1. валидный `Telegram.WebApp.initData`, подписанный Telegram;
2. Telegram ID из `ADMIN_USER_IDS`;
3. правильный админ-пароль.

`initDataUnsafe` используется только Telegram-клиентом для UI; backend доверяет
только валидированному `initData`.

## База данных

Mini App не создаёт вторую экономику и не копирует базу.
Бот и Mini App работают с одной `/app/data/murrlybot.sqlite3`.

При обновлении НЕ удаляй `/app/data/murrlybot.sqlite3`.
