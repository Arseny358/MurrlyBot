# MurrlyBot v2

Telegram RP-бот для групповых чатов.

## Возможности

- RP-действия только ответом на сообщение.
- 25+ действий и алиасы.
- Несколько случайных фраз для каждого действия.
- Кулдаун против спама.
- SQLite-статистика.
- Близость между каждой парой участников.
- Команда `отношения` ответом на сообщение.
- `рп профиль`.
- `рп топ`.
- `рп команды`.

## Bothost

- Python 3.11
- Главный файл: `main.py`
- Long polling
- Домен не нужен
- Dockerfile не нужен
- База сохраняется в `DATA_DIR/murrlybot.sqlite3`

## Telegram

Для обычных текстовых RP-команд необходимо отключить Privacy Mode у бота:
`@BotFather` -> `/setprivacy` -> выбрать бота -> Disable


## 18+ RP-команды

Всегда доступны и работают ответом на сообщение:
`трахнуть`, `выебать`, `жёстко трахнуть`, `заняться сексом`,
`доминировать`, `подчинить`, `оседлать`, `прижать`,
`отшлёпать`, `раздеть`, `соблазнить`, `раздразнить`,
`возбудить`, `довести`, `поиграть пожёстче`.

Команды с сексуальным насилием не добавлены.


## Формат ответов 18+

Ответы сокращены до простых действий без метатекста про RP, сцены или "взрослое продолжение".
