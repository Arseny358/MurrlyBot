# MurrlyBot v2

Telegram RP-бот для групповых чатов.

## Возможности

- RP-действия только ответом на сообщение.
- 25+ действий и алиасы.
- Несколько случайных фраз для каждого действия.
- Кулдаун против спама.
- SQLite-статистика.
- Близость между каждой парой участников.
- Команда `отношения` ответом на сообщение.
- `рп профиль`.
- `рп топ`.
- `рп команды`.

## Bothost

- Python 3.11
- Главный файл: `main.py`
- Long polling
- Домен не нужен
- Dockerfile не нужен
- База сохраняется в `DATA_DIR/murrlybot.sqlite3`

## Telegram

Для обычных текстовых RP-команд необходимо отключить Privacy Mode у бота:
`@BotFather` -> `/setprivacy` -> выбрать бота -> Disable


## 18+ RP-команды

Всегда доступны и работают ответом на сообщение:
`трахнуть`, `выебать`, `жёстко трахнуть`, `заняться сексом`,
`доминировать`, `подчинить`, `оседлать`, `прижать`,
`отшлёпать`, `раздеть`, `соблазнить`, `раздразнить`,
`возбудить`, `довести`, `поиграть пожёстче`.

Команды с сексуальным насилием не добавлены.


## Формат ответов 18+

Ответы сокращены до простых действий без метатекста про RP, сцены или "взрослое продолжение".

## 🍯 Раздача мёдика

В этой версии добавлена внутренняя копилка мёдика и автоматические раздачи.

- В одном улье: 300 🍯.
- Один пользователь может забрать мёдик один раз за раздачу.
- Обычный улов: случайно от 30 до 40 🍯.
- Если в улье осталось меньше 30 🍯, последний участник забирает весь остаток.
- Команда `копилка` показывает баланс и статистику.
- Каждый день создаётся два случайных времени по системным часам сервера:
  - первая раздача: 09:00–15:00;
  - вторая раздача: 16:00–23:00.
- После первого запуска этой версии выполняется одна демонстрационная раздача.
  В базе сохраняется отметка, поэтому после дальнейших перезапусков демо не повторяется.
- Если при первом запуске в базе ещё нет известного группового чата, демо запустится при первой новой активности в группе.


## Ограничение времени раздачи

Каждая раздача мёдика длится ровно 1 час.

В исходном сообщении показывается точное время закрытия, например:
`⏰ Раздача закроется в 18:42.`

После истечения часа кнопка убирается, раздача закрывается, а оставшийся мёдик сгорает.
Одноразовая тестовая раздача повторно не запускается.


## Время раздач

MurrlyBot использует единое фиксированное время UTC+3 независимо от системных часов Bothost.

По этим часам:
- первая раздача: 09:00–15:00;
- вторая раздача: 16:00–23:00;
- закрытие: ровно через 1 час после запуска.

Существующая активная раздача после первого запуска этой версии автоматически
получает поправку времени +3 часа. Повторно миграция не выполняется.

## Система браков

Добавлен отдельный модуль `marriage.py`.

Команды:
- `заключить брак` — ответом на сообщение участника;
- `брак` / `мой брак` — карточка текущего брака;
- `развестись` / `развод` — ручной развод с подтверждением.

Предложение брака показывает две кнопки: `Принять` и `Отказаться`.
Нажать их может только пользователь, которому сделано предложение.
Каждый пользователь может состоять только в одном активном браке.

Здоровье брака:
- стартует со 100%;
- уменьшается на 1% каждые 3 полных дня;
- при 0% автоматического развода нет;
- обычные (не 18+) RP-команды между супругами восстанавливают здоровье;
- максимум восстановления — 3% в сутки;
- 18+ RP-команды на здоровье брака не влияют.

Карточка брака показывает супругов, здоровье, состояние и время существования брака.


## Медовая ферма

Команда: `ферма`

Ферма создаётся бесплатно на 1 уровне при первом открытии.

Баланс:
- Уровень 1: 10 🍯/сутки, вместимость 15 🍯, улучшение 200 🍯
- Уровень 2: 15 🍯/сутки, вместимость 25 🍯, улучшение 450 🍯
- Уровень 3: 20 🍯/сутки, вместимость 35 🍯, улучшение 800 🍯
- Уровень 4: 25 🍯/сутки, вместимость 50 🍯, улучшение 1400 🍯
- Уровень 5: 30 🍯/сутки, вместимость 70 🍯, максимальный уровень

Мёдик производится по реальному прошедшему времени. Когда соты заполнены,
производство останавливается до сбора.

Кнопки:
- `🍯 Собрать мёдик`
- `⬆️ Улучшить`

## Магазин подарков

Команду `магазин` нужно отправить ответом на сообщение получателя.

Подарки:
- 🌹 Роза — 20 🍯
- 🍫 Шоколадка — 35 🍯
- 🧸 Плюшевый мишка — 75 🍯
- 💐 Букет цветов — 120 🍯
- 💎 Кристалл — 250 🍯
- 👑 Золотая корона — 500 🍯

Подарки навсегда остаются в коллекции получателя и не продаются обратно.

Команда `подарки` показывает свою коллекцию.
Если отправить `подарки` ответом на сообщение, показывается коллекция этого участника.

Если подарок отправляется супругу, он немного поддерживает здоровье брака:
0.1–1% в зависимости от подарка. На подарки и обычные RP вместе действует
существующий лимит восстановления здоровья брака: максимум +3% в сутки.


## Обновлённая механика магазина и подарков

Теперь покупка и дарение разделены.

### Магазин

Команда:

```text
магазин
```

Открывает магазин без reply.

Покупка:
- списывает мёдик у покупателя;
- кладёт подарок в личную коллекцию покупателя;
- не отправляет подарок другому пользователю автоматически;
- не влияет на здоровье брака.

После покупки магазин остаётся открытым.

### Подарить

Команда:

```text
подарить
```

отправляется ответом на сообщение получателя.

Бот показывает только подарки, которые уже есть в коллекции дарителя.
На кнопках указывается количество, например:

`🧸 Плюшевый мишка ×2`

После выбора:
- один экземпляр удаляется у дарителя;
- один экземпляр добавляется получателю;
- если получатель является супругом, применяется бонус здоровья брака;
- используется общий дневной лимит восстановления здоровья брака +3%.

Команда `подарки` по-прежнему показывает коллекцию.
Уже существующие подарки в базе сохраняются и становятся доступными для передачи.


## RP-событие «Массовая оргия»

Добавлено ежедневное 18+ RP-событие без графических описаний.

После первого запуска этой версии:
- событие один раз запускается сразу как демонстрация;
- в этот же день штатный запуск в 23:00 пропускается;
- затем событие автоматически запускается каждый день в 23:00 по тем же часам UTC+3, что и система мёдика.

Сообщение содержит кнопку:
`🔥 Присоединиться`

Правила:
- один пользователь может присоединиться один раз;
- исходное сообщение показывает количество участников;
- событие длится 1 час;
- в 00:00 штатное событие закрывается и кнопка убирается;
- после перезапуска повторного события за тот же день не создаётся;
- одноразовая демонстрация после следующих перезапусков не повторяется.


## Изменение длительности события

Событие «Массовая оргия» теперь длится 2 часа.
Штатный запуск в 23:00 закрывается в 01:00.


## Штатный запуск события

Одноразовый демонстрационный запуск события «Массовая оргия» удалён.

Теперь событие работает только по расписанию:
- каждый день в 23:00 по времени бота UTC+3;
- длительность — 2 часа;
- закрытие штатного события — в 01:00;
- после перезапуска бот не создаёт дубль события за тот же день.


## Анкеты пользователей

Команда:

```text
анкета
```

Без reply показывает собственную анкету.

Если отправить `анкета` ответом на сообщение другого участника,
бот показывает анкету этого участника.

Поля анкеты:
- имя / ник;
- возраст;
- город;
- пол;
- о себе.

В собственной анкете есть кнопка `✏️ Заполнить анкету` или
`✏️ Редактировать анкету`.

Редактирование идёт по отдельным полям. Для текстовых полей символ `-`
очищает выбранное значение.

Ограничения:
- имя / ник — до 40 символов;
- возраст — от 1 до 120;
- город — до 60 символов;
- о себе — до 400 символов.

Редактировать можно только собственную анкету. Чужие анкеты доступны только
для просмотра.


## Защита от Telegram Flood control

Добавлена глобальная защита исходящих запросов Telegram.

Причина:
Telegram может вернуть `429 Too Many Requests / TelegramRetryAfter`,
если бот слишком часто отправляет сообщения в один чат.

Теперь:
- групповые `SendMessage` для каждого чата проходят через общую очередь;
- бот выдерживает не менее ~1 секунды между сообщениями в одном групповом чате;
- бот не выпускает больше 20 `SendMessage` за 60 секунд в одной группе;
- если Telegram всё равно возвращает `RetryAfter`, бот ждёт указанное сервером
  время + небольшой запас и автоматически повторяет запрос;
- исключение `TelegramRetryAfter` больше не должно обрывать обработчик RP-команды.

Ограничитель работает глобально для всех обычных текстовых сообщений бота,
а не только для одной RP-команды.


## Исправление команды анкеты

Исправлена маршрутизация анкеты.

Работают варианты:
- `анкета`
- `моя анкета`
- `/анкета`
- `/profile`
- `/anketa`

Команда анкеты теперь обрабатывается до общего отсечения slash-команд.
Если пользователь остался в режиме редактирования поля, повторная команда
анкеты сбрасывает этот режим и открывает карточку вместо записи слова
«анкета» в поле.
