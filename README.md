# MurrlyBot — Admin + VIP + Backup update

Версия для Bothost / Python 3.11 / aiogram 3.x.

## Что изменилось

- Удалено ежедневное событие «Массовая оргия». `mass_event.py` теперь безопасная заглушка; старые таблицы БД не удаляются.
- Удалён автоматический одноразовый демо-запуск «Внезапной раздачи мёдика» после обновления.
- Новые цены фермы по умолчанию: 75 / 150 / 275 / 450 🍯.
- Добавлена админ-панель в личных сообщениях с ботом.
- Цены фермы, производство, вместимость, раздачи, подарки и VIP теперь хранятся в SQLite и меняются без перезапуска бота.
- Добавлена VIP-система на 7 и 30 дней.
- Добавлены ручной и автоматический бэкапы SQLite прямо в Telegram.
- Сохранены анкеты, RP, браки, подарки, фермы, кошельки и статистика активности.

## Переменные Bothost

Обязательные:

```text
BOT_TOKEN=...
DATA_DIR=/app/data
```

Для админ-панели добавьте ОДИН из вариантов:

```text
ADMIN_PASSWORD=ваш_пароль
```

или безопаснее SHA-256:

```text
ADMIN_PASSWORD_HASH=sha256_в_hex
```

Если задан `ADMIN_PASSWORD_HASH`, он имеет приоритет над `ADMIN_PASSWORD`.
Пароль в исходниках не хранится.

Дополнительно можно ограничить доступ конкретным Telegram ID:

```text
ADMIN_USER_IDS=123456789,987654321
```

Если переменная не задана, доступ определяется только паролем.

## Админ-панель

Напишите боту **в личные сообщения**:

```text
Авторизация
```

После правильного пароля сессия действует 24 часа. Панель позволяет менять:

- 🐝 цены улучшения фермы;
- 🍯 производство каждого уровня;
- 📦 вместимость каждого уровня;
- 🎉 включение раздач, временные окна, фонд, min/max и длительность;
- 🚀 ручной запуск раздачи во всех зарегистрированных группах;
- 🎁 цены подарков и бонус здоровью брака;
- 👑 цену и бонусы VIP;
- 📊 статистику;
- 📋 журнал изменений;
- 💾 создание бэкапа и ежедневный автобэкап.

Все изменения применяются сразу и сохраняются в `/app/data/murrlybot.sqlite3`.

## VIP — значения по умолчанию

- план 1: 7 дней — 250 🍯
- план 2: 30 дней — 750 🍯
- +20% к производству фермы
- +25% к вместимости фермы
- +10% к порции во внезапной раздаче
- 👑 отметка VIP в анкете

Сроки, цены и бонусы меняются из админки.

Игрок открывает VIP командами:

```text
vip
вип
```

или `/vip`.

## Раздачи

По умолчанию:

- первая случайная раздача: 09:00–15:00;
- вторая: 16:00–23:00;
- фонд 300 🍯;
- порция 30–40 🍯;
- длительность 60 минут.

После рестарта или обновления **новая тестовая раздача не создаётся**. Уже активная раздача может быть восстановлена/обновлена ботом.

## Бэкапы

Функция Bothost на некоторых нодах не реализована, поэтому MurrlyBot делает бэкап самостоятельно через SQLite Backup API.

Админ-панель → **⚙️ Система и бэкап** → **💾 Создать бэкап сейчас**.

Бот отправит ZIP в личные сообщения. Внутри:

```text
murrlybot.sqlite3
BACKUP_INFO.txt
```

Автобэкап по умолчанию выключен. Его можно включить в админке и выбрать время. Архив отправляется всем пользователям, которые хотя бы один раз успешно авторизовались как администраторы.

Для ручного восстановления остановите бота и восстановите файл как:

```text
/app/data/murrlybot.sqlite3
```

Не заменяйте рабочую БД при обычном обновлении кода.

## Безопасное обновление

Обновление НЕ удаляет `/app/data/murrlybot.sqlite3`.
Новые таблицы создаются через `CREATE TABLE IF NOT EXISTS`.

Добавляются таблицы:

```text
bot_config
admin_users
admin_sessions
admin_audit
vip_subscriptions
vip_purchases
```

Существующие пользовательские данные не должны сбрасываться.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Ожидаемый маркер в логах:

```text
MurrlyBot admin + VIP + backup update starting...
```


## Правила чата

Любой пользователь может написать `Правила` или `/rules`, чтобы получить текущие правила. Текст редактируется только из личной админ-панели: `Авторизация` → `📜 Правила` → `✏️ Изменить правила`. Правила хранятся в SQLite и применяются сразу, без перезапуска бота.
