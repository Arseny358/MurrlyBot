# MurrlyBot — Economy Update v2

Крупное обновление Mini App. Устанавливается поверх текущего проекта.
Существующую `/app/data/murrlybot.sqlite3` НЕ удалять и НЕ заменять.

## Что добавлено

### Подарки
- Продажа подарков из Mini App.
- По умолчанию возвращается 60% текущей цены.
- Процент редактируется в Mini App админ-панели.
- История продаж сохраняется в SQLite.

### Медовая биржа HNY
- Один общий игровой рынок для всех пользователей.
- HNY — только внутриигровой актив, без реальных денег.
- Автоматическое изменение цены.
- Графики 1ч / 6ч / 24ч / 7д.
- Покупка HNY за мёдик.
- Продажа HNY обратно в мёдик.
- Комиссии покупки/продажи.
- Портфель, себестоимость, нереализованный и реализованный результат.
- История сделок.
- Админ: волатильность, диапазон цены, комиссии, частота обновления,
  ручной импульс вверх/вниз и перезапуск рынка.

## Обновление через веб GitHub

1. Распакуй архив.
2. Открой корень репозитория MurrlyBot.
3. `Add file -> Upload files`.
4. Загрузи:
   - config.py
   - farm.py
   - gifts.py
   - miniapp_server.py
   - start.py
   - daily_tasks.py
   - exchange.py
5. GitHub предложит заменить существующие одноимённые файлы — это правильно.
6. Сделай commit.
7. Открой папку `miniapp_static` в GitHub.
8. `Add file -> Upload files`.
9. Загрузи туда:
   - index.html
   - style.css
   - app.js
10. Сделай второй commit.

## Bothost

Ничего нового в переменные добавлять не нужно.

Оставить:
- BOT_TOKEN
- DATA_DIR=/app/data
- ADMIN_USER_IDS
- ADMIN_PASSWORD (или ADMIN_PASSWORD_HASH)

Запуск:
- главный файл: `start.py`
- внутренний порт: `8000`
- домен/HTTPS: оставить текущий

После GitHub commit сделай новый деплой / обновление репозитория.

В консоли должна появиться строка:
`MurrlyBot Economy Update v2 starting on 0.0.0.0:8000`

Проверка:
`https://ТВОЙ-ДОМЕН/health`

Ожидается:
`{"ok":true,"service":"murrlybot-miniapp","economy_update":2}`
