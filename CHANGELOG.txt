- Добавлена публичная команда «Правила» и /rules.
- Текст правил хранится в SQLite и меняется без перезапуска.
- В админ-панель добавлен раздел «📜 Правила».
- Редактирование доступно только авторизованному администратору из ADMIN_USER_IDS.
- Изменение правил записывается в журнал администратора.

MurrlyBot — Admin + VIP + Backup update
=======================================

1. Удалено событие «Массовая оргия».
   - main.py больше не импортирует и не запускает его.
   - mass_event.py заменён заглушкой.
   - старые таблицы SQLite намеренно не удаляются.

2. Удалена одноразовая демо-раздача мёдика после обновления.
   - после перезапуска новая тестовая раздача не создаётся.
   - остаются только штатные раздачи по расписанию и ручной запуск администратором.

3. Ферма:
   - цены по умолчанию: 75 / 150 / 275 / 450 мёдика;
   - производство и вместимость каждого уровня теперь изменяются из админки;
   - изменения применяются без перезапуска;
   - VIP-бонусы учитываются в производстве и вместимости.

4. Админ-панель в ЛС:
   - команда «Авторизация»;
   - пароль через ADMIN_PASSWORD или ADMIN_PASSWORD_HASH;
   - опциональная привязка к ADMIN_USER_IDS;
   - сессия 24 часа;
   - ферма, раздачи, подарки, VIP, статистика, журнал, система и бэкап.

5. Раздачи:
   - включение/выключение;
   - два редактируемых временных окна;
   - редактируемый фонд, min/max порции и длительность;
   - ручной запуск во всех зарегистрированных группах;
   - VIP-бонус к порции.

6. Подарки:
   - цена каждого подарка редактируется;
   - бонус здоровью брака каждого подарка редактируется.

7. VIP:
   - два плана;
   - по умолчанию 7 дней / 250 мёдика и 30 дней / 750 мёдика;
   - сроки обоих планов можно менять;
   - цены можно менять;
   - бонус производства фермы +20%;
   - бонус вместимости +25%;
   - бонус порции раздачи +10%;
   - VIP отображается в анкете.

8. Бэкап:
   - ручной бэкап через админ-панель;
   - SQLite Backup API для консистентной копии;
   - ZIP отправляется администратору прямо в Telegram;
   - опциональный ежедневный автобэкап;
   - время и количество локальных копий редактируются.

9. Безопасность данных:
   - /app/data/murrlybot.sqlite3 не удаляется и не пересоздаётся;
   - legacy_import.py заменён безопасной заглушкой;
   - новые таблицы создаются через CREATE TABLE IF NOT EXISTS.
